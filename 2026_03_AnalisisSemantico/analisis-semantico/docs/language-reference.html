1. Estructura del Programa

Todo programa debe comenzar con la palabra clave STARTPROG y terminar con ENDPROG. Las instrucciones se escriben entre estas dos palabras, una por línea.

Sintaxis

STARTPROG
  instrucciones...
ENDPROG

Reglas

  • El programa debe iniciar con STARTPROG en la primera línea.
  • El programa debe terminar con ENDPROG.
  • Cada instrucción ocupa su propia línea.
  • Los espacios y tabulaciones entre tokens son ignorados.

2. Variables y Asignaciones

El lenguaje soporta tres tipos de datos. Cada tipo tiene su propio prefijo de declaración.

PrefijoTipoTipo Java generadoEjemplo de valor
I>intint42, 10 + 5 * 2
S>StringString"Hola mundo"
B>booleanbooleanT, F, T and F

Asignación entera — I>

Declara una variable entera. El lado derecho puede ser cualquier expresión aritmética.

I> nombre = expresión_aritmética
I> x = 10
I> y = 5
I> resultado = x + y * 2

Asignación de cadena — S>

Declara una variable de texto. El valor debe estar entre comillas dobles y puede contener letras, números, espacios y guiones bajos.

S> nombre = "texto"
S> saludo = "Hola mundo"
S> usuario = "Juan_123"

Asignación booleana — B>

Declara una variable booleana. El lado derecho puede ser cualquier expresión booleana.

B> nombre = expresión_booleana
B> activo = T
B> inactivo = F
B> resultado = T and (F or activo)

5. Condicionales

Ejecuta un bloque de instrucciones si la condicion booleana es verdadera.

IF expresion_booleana THEN
  instrucciones
ENDIF
  • La condicion puede ser cualquier expresion booleana valida.
  • El bloque puede contener asignaciones, PRINT u otros condicionales.
  • No existe ELSE en esta version del lenguaje.
I> edad = 18
IF edad >= 18 THEN
  PRINT "Mayor de edad"
ENDIF
B> activo = T
IF activo and (edad > 10) THEN
  PRINT "Activo y mayor de 10"
ENDIF

6. Validacion Semantica de Tipos

El compilador realiza analisis semantico durante la visita del arbol de parseo. Se verifican las siguientes reglas:

Reglas de tipo

  • Una variable usada en una expresion aritmetica (+, -, *, /) debe ser de tipo int.
  • Una variable usada directamente en una expresion booleana (sin comparacion) debe ser de tipo boolean.
  • Toda variable debe estar declarada antes de usarse.

Errores detectados

        }
    }
